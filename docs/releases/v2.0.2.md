# v2.0.2 (build 79)

## Motivo
Build virgem para upload limpo na Play Store. Os versionCode 77 (produção) e 78 já
estavam consumidos/na biblioteca de versões, o que fazia o Google recusar novos uploads
com "versionCode já existe". O 79 é um código nunca usado, para carregar de fresco numa
faixa sem conflitos de duplicado.

## Alterações
- Bump versão: 2.0.1 → 2.0.2, versionCode 78 → 79 (app.json + package.json + build.gradle)
- Sem alterações de código face à v2.0.0/2.0.1 — binário continua sem `AD_ID`, sem SDKs
  de publicidade e sem permissões de localização
- AAB assinado com a keystore de produção (SHA1 C8:0B:28:E9:EF:84:19:BD:CE:72:C7:DE:5C:A7:7E:83:E6:58:0F:22)

## Regra de ouro na Play Console (evitar o erro de duplicado)
- Carregar o 79 UMA vez, numa faixa. Para as restantes faixas usar "Adicionar da
  biblioteca de versões" — NUNCA voltar a carregar o mesmo ficheiro.
- Se uma faixa tiver um rascunho preso, "Descartar versão" antes de criar nova.

## Verificação esperada
- Manifesto do AAB sem `com.google.android.gms.permission.AD_ID`
- SHA1 confirmado via keytool
