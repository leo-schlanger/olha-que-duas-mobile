# v2.0.1 (build 78)

## Motivo
Rebuild técnico para destravar a publicação na Play Store. A declaração de "ID de
publicidade" ficava marcada como incompleta porque builds antigos (≤ build 75, ainda
com AdMob/permissão `AD_ID`) continuavam ativos em faixas de teste (fechado e interno).
O `versionCode` 77 já tinha sido consumido em produção e não pode ser reutilizado, por
isso gera-se um artefacto novo (build 78) limpo para promover a todas as faixas.

## Alterações
- Bump versão: 2.0.0 → 2.0.1, versionCode 77 → 78 (app.json + package.json)
- Sem alterações de código face à v2.0.0 — binário continua sem `AD_ID`, sem SDKs de
  publicidade e sem permissões de localização
- AAB assinado com a keystore de produção (SHA1 C8:0B:28:E9:EF:84:19:BD:CE:72:C7:DE:5C:A7:7E:83:E6:58:0F:22)

## Procedimento na Play Console (manual)
1. Upload do `builds/olha-que-duas-v2.0.1-build78.aab`
2. Promover o mesmo build 78 para Teste fechado e Teste interno (substitui os builds ≤75)
3. Conteúdo do app → ID de publicidade → "Não" → Guardar
4. Visão geral da publicação → Enviar alterações para análise

## Verificação esperada
- Manifesto do AAB sem `com.google.android.gms.permission.AD_ID`
- SHA1 confirmado via keytool
