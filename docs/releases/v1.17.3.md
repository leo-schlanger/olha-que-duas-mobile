# v1.17.3 — Background artwork fix + Location permission hardening

**Build 74 | 2026-05-04**

## Correcao: Artwork nao atualiza em background

- `MediaService.kt`: dedup do polling nativo agora compara title + artist + **artworkUri** (antes ignorava artwork)
- Quando o artwork mudava mas title/artist permaneciam iguais, `updateMetadata()` nunca era chamado
- O lado JS (`radioService.ts`) ja fazia o dedup corretamente, mas em background a thread JS esta suspensa e so o polling nativo corre
- Novo campo `lastPolledArtUrl` para tracking, resetado ao iniciar polling (formatos file:// vs https:// diferem)
- Log melhorado: mostra ultimos 50 chars da URL do artwork

## Correcao: Permissao de localizacao

- `useLocation.ts`: logging de diagnostico no fluxo de inicializacao (estado, dialog, resultado)
